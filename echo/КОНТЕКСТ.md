# echo/ — канал обратной связи терминала

Скрытый носитель петли: сервер отвечает ИИ тем же путём, каким получает код.

## Как работает

1. ИИ кладёт код в kord-bridge → сервер забирает (update-loop.sh).
2. После выполнения `bridge/echo.sh` дописывает вывод терминала
   (команда, код выхода, лог, таймстемп) в `echo/ответ-терминала.md`.
3. Скрипт коммитит файл обратно в kord-bridge — тем же ключом, без секретов.
4. ИИ читает ответ в следующей сессии. Петля замкнута.

## Подключение в цикл

В `bridge/update-loop.sh` после шага обновления добавь одну строку:

    ./bridge/echo.sh "обновление: $(git log -1 --oneline)"

Или без аргумента — сервер пришлёт самопроверку (uptime, диск, pm2, коммит).

## Правила

- В эхо не пишем секреты и токены — только видимое: команды и вывод.
- Файл растёт накопительно; при разрастании — архивировать в echo/архив/.
