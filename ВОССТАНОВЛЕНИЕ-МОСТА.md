## 2. Как живёт главная рука

На телефоне:

- `~/kord-bridge` — клон `DenAB-NVS/kord-bridge`
- `~/kord-echo` — клон `KordinapsArhanHome/kord-echo`
- `~/kord-cikl.sh` — цикл v3
- `~/kord-sluzhba.sh` — бесконечная служба, `sleep 30`
- `~/kord-vypolneno.txt` — журнал исполненных телефонных заданий
- `~/.termux/boot/kord-boot.sh` — поднимает службу после перезагрузки

**Цикл v3:**

1. `termux-wake-lock` удерживает процесс бодрым.
2. Телефон забирает свежий мост (`git fetch` + `reset --hard origin/main`).
3. Исполняет только новые `телефон/задания/*.sh`.
4. Создаёт пульс раз в 10 минут или результат немедленно.
5. Коммитит изменения в `kord-echo` и пушит их напрямую в GitHub.

**Дозор 0003:** каждые 5 минут берёт веб-версии `freelancetavern`, `distantsiya`, `it_freelance`, `python_jobs_ru`; пишет в `~/kord-echo/дозор/`. Кординапс читает их через `list_commits → get_commit(full_patch)` и готовит ответы. Дозор не пишет от имени владельца и не делает рассылок.

**Будильник 0004:** wake-lock повторяется в каждом цикле. Автозапуск после ребута обеспечен Termux:Boot.

## 3. Живая проверка (сначала всегда она)

### Из сессии Кординапс

1. `list_commits` для `KordinapsArhanHome/kord-echo`, `perPage: 5`.
2. Свежий коммит ≤15 минут — главная рука жива.
3. При новом задании — ждать около 30 секунд до исполнения плюс время самого задания.
4. Дамп дозора искать в патче последнего коммита по путям `дозор/*.txt`.

### С телефона

Только если что-то молчит:

```bash
tail -30 ~/kord-sluzhba.log
pgrep -af kord-sluzhba.sh
```

Если службы нет:

```bash
termux-wake-lock
nohup bash ~/kord-sluzhba.sh >/dev/null 2>&1 &
```

Если телефон перезагрузился — сначала открыть Termux:Boot один раз (если Android его остановил), затем проверить `pgrep`. Не переустанавливать всё подряд.

## 4. Установка новой руки

Полная короткая инструкция лежит в `телефон/ИНСТРУКЦИЯ-НОВЫЙ-ТЕЛЕФОН.md`.

Сжатый путь:

```bash
pkg update -y && pkg install -y git
git clone https://github.com/DenAB-NVS/kord-bridge.git
cd kord-bridge && bash termux-zapusk.sh
```

Установщик просит токен **KordinapsArhanHome**. Токен вставляется только в Termux, никогда не в чат, не в GitHub-файлы, не в эхо. После установки:

```bash
mkdir -p ~/.termux/boot
cp ~/kord-bridge/телефон/boot/kord-boot.sh ~/.termux/boot/
chmod +x ~/.termux/boot/kord-boot.sh
```

Android: для Termux, Termux:Boot и Termux:API → Батарея → «Без ограничений».

### Известный шов авторизации

При первом пуше Git может спросить `Username for https://github.com` и `Password`.

- Username: `KordinapsArhanHome`.
- Вместо password: тот же GitHub fine-grained token.
- После успешного запуска выполнить **одной отдельной командой**:

```bash
gh auth setup-git
```

Это привязывает Git к авторизации `gh`, чтобы будущие пуши не спрашивали пароль. Если команды «не видны» в Termux, ориентироваться на результат: строка `[1] PID` означает, что фоновая служба запущена; `ls -l ~/.termux/boot/` с `kord-boot.sh` означает, что автозапуск готов.

## 7. Непереходимые правила

1. Токены, пароли, SSH-ключи — никогда в мост, эхо, дом, чат или коммиты.
2. Публичны мост и эхо: только код, результаты и обезличенные статусы.
3. Каждое задание маленькое, проверяемое, с явным выводом.
4. Сначала проверка, потом лечение; не переустанавливать из тревоги.
5. Телефонная и серверная очереди не смешиваются.
6. Действия к живым людям — только руками владельца и после явного просмотра текста.
7. Внешние необратимые изменения GitHub требуют подтверждения владельца в интерфейсе; это страж платформы, его не обойти. Связанные изменения собирать в один коммит, чтобы не множить подтверждения.
