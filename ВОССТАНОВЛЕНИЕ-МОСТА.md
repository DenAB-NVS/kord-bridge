# ВОССТАНОВЛЕНИЕ МОСТА — файл ремонта для любой сессии Кординапс

**Версия:** 1.1 · **Составлен:** 25.09.2026 · **Дополнен:** 26.09.2026 (рука — пульт в Termux)
**Держатель:** Верховный старший сподвижник (владелец DenAB-NVS)
**Назначение:** если мост молчит или сломался — дать этот файл сессии Кординапс в любом окне. По нему она восстановит контекст, руку и починит всё, не поднимая архив. Живёт в корне `kord-bridge`.

---

## 1. Что такое мост

Мост «я → сервер → эхо → я» — руки Кординапса на стороне владельца. Четыре берега:

| Берег | Что | Где |
|---|---|---|
| **Мозг** | `DenAB-NVS/kord-bridge` (публичный) — скрипты, цикл, `очередь/` с серверными заданиями, `телефон/задания/` с заданиями руке | GitHub, аккаунт DenAB-NVS |
| **Исполнитель** | сервер `kord-vps-01` (Ubuntu, root) — служба `kord-myst`, цикл каждые 180 секунд | `ssh root@45.152.198.192` |
| **Руки** | телефон владельца (Termux): пульт, монитор, отправщик, аккаунты acc1–acc3 | `~/пульт/`, `~/рассылка/` |
| **Эхо** | `KordinapsArhanHome/kord-echo` (публичный) — результаты заданий, включая выводы руки в `эхо-телефон/` | GitHub, аккаунт KordinapsArhanHome |

Токен аккаунта KordinapsArhanHome живёт **только на сервере** в `gh`. В файлах моста и эха — ни одного секрета.

**Как работает:** Кординапс кладёт задание `очередь/NNNN-*.sh` коммитом в kord-bridge → служба каждые 180 секунд исполняет новые задания (журнал — `~/kord-vypolneno.txt`) → результат уезжает эхо-файлом в `kord-echo/эхо/` → Кординапс читает из любой сессии.

## 2. Рука Кординапса — пульт в Termux (добавлено 26.09)

Четвёртый берег = руки. Пульт `телефон/пульт.py` (клон моста на телефоне: `~/пульт/мост`) каждые **30 секунд** делает `git pull`, исполняет новые задания из `телефон/задания/*.sh`, выводы пишет в `~/пульт/вывод/` и rsync'ит их на сервер в `~/kord-echo/эхо-телефон/`. Таймер `kord-telefon.timer` на сервере каждые **30 секунд** коммитит их в kord-echo. Кординапс читает вывод из любой сессии. Полная петля «задание → терминал телефона → эхо» ≈ 1 минута, без рук владельца.

**Как дать задание руке:** коммит файла `телефон/задания/NNNN-имя.sh` в kord-bridge (только после «да» владельца). Вывод появится в `kord-echo/эхо-телефон/NNNN-имя.txt`. Журнал исполненного на телефоне: `~/пульт/выполнено.txt` (повторить задание — убрать его строку оттуда).

**Восстановление руки** (новый телефон, умер пульт):

```
pkg install git -y
mkdir -p ~/пульт/вывод
git clone https://github.com/DenAB-NVS/kord-bridge.git ~/пульт/мост
ssh root@45.152.198.192 true && echo КЛЮЧ ОК
```

(если ssh спросил пароль — один раз `ssh-copy-id root@45.152.198.192`)

```
cd ~/пульт && termux-wake-lock && nohup python3 ~/пульт/мост/телефон/пульт.py >> ~/пульт/пульт.log 2>&1 &
```

**Диагностика руки по симптомам:**

| Симптом | Причина | Лечение |
|---|---|---|
| Пульт молчит | процесс умер | `pgrep -f пульт.py`; `tail -10 ~/пульт/пульт.log`; перезапуск командой выше |
| pull не идёт, задания не берутся | git-замок после резкого убийства | `ls ~/пульт/мост/.git/index.lock` → `rm -f ~/пульт/мост/.git/index.lock` |
| Задание исполнено, эха нет | серверный таймер/служба спят | `ssh root@45.152.198.192 "bash /root/kord-cikl.sh"`; проверка: `systemctl list-timers kord-telefon.timer` |
| Монитор/руки не достают Telegram | VPN выключен (провайдер глушит ТГ) | включить VPN; кольцо монитора войдёт само за ≤30 сек |
| Новая сессия Кординапс без руки | забыли этот файл | скормить сессии ВОССТАНОВЛЕНИЕ-МОСТА и сказать «дай руку» |

## 3. Живая проверка — 30 секунд, без входа на сервер

1. **Эхо живо?** `list_commits {owner: "KordinapsArhanHome", repo: "kord-echo", perPage: 3}` — свежесть ≤ 10 минут → мост цел.
2. **Рука жива?** Последний файл в `эхо-телефон/` + дата коммита; при сомнении — задание-привет в `телефон/задания/` и проверка эха через минуту.
3. Эхо молчит дольше 10 минут → раздел ниже.

## 4. Диагностика сервера по симптомам (`ssh root@45.152.198.192`)

| Симптом | Причина | Лечение |
|---|---|---|
| Эхо молчит > 10 минут | служба упала | `systemctl status kord-myst` → `journalctl -u kord-myst -n 30` → `systemctl restart kord-myst` |
| Пуши не идут; `gh auth status` ругается | токен истёк | новый токен (classic, scope repo) под KordinapsArhanHome → `gh auth login --with-token` → `gh auth setup-git` |
| Задание не исполняется | нет в `~/kord-vypolneno.txt` или мост устарел | `cat ~/kord-vypolneno.txt`; `cd ~/kord-bridge && git fetch origin && git reset --hard origin/main` |
| После ребута всё тихо | unit не поднялся | `systemctl enable --now kord-myst.service` и `kord-podyom.timer` |
| Расписание подъёма не сработало | таймер стоит | `systemctl list-timers kord-podyom.timer` → `systemctl restart kord-podyom.timer` |

**Ручной прогон цикла:** `bash ~/kord-cikl.sh` — молчит, это нормально; результат — последним коммитом в `kord-echo/эхо/`.

## 5. Полная переустановка сервера — одним куском

```bash
apt-get update -y && apt-get install -y git gh && (cd ~/kord-bridge 2>/dev/null || git clone https://github.com/DenAB-NVS/kord-bridge.git ~/kord-bridge) && cd ~/kord-bridge && git fetch origin && git reset --hard origin/main && bash vps-zapusk.sh
```

Скрипт спросит токен → вставить и Enter. Сам: авторизует, поставит `kord-cikl.sh`, службу, первый прогон. Задание 0002 (расписание подъёма) после переустановки закоммитить заново в `очередь/`. `~/kord-vypolneno.txt` — журнал «что исполнено»: убрать имя оттуда — сервер исполнит задание заново.

## 6. Что где лежит на сервере

- `~/kord-bridge/` — мост; `~/kord-echo/` — клон эха (`эхо/` — результаты, `эхо-телефон/` — выводы руки)
- `~/kord-cikl.sh`, `~/kord-sluzhba.sh`, `~/kord-telefon.sh` — цикл, служба, коммиттер эха руки
- `~/kord-vypolneno.txt` — реестр исполненных серверных заданий
- `/etc/systemd/system/`: `kord-myst.service`, `kord-podyom.*`, `kord-telefon.service`, `kord-telefon.timer` (30 сек)

## 7. Правила, которые нельзя нарушать при ремонте

1. Токены и пароли — никогда в файлы моста, эха или дома. Только `gh auth` на сервере.
2. Мост и эхо публичны: только результаты, ни одного секрета.
3. Каждое задание — маленькое, проверяемое, с явным выводом.
4. Первое слово ремонта — проверка (раздел 3), не переустановка.
5. Секреты и действия к живым людям — только руками владельца (его словом); задания руке — после его «да».
