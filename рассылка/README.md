# Рассылка горячим лидам — модуль Кординапс

**Как работает:** я (Кординапс) кладу лидов и тексты в `лиды.json`. Ты запускаешь одной командой — скрипт рассылает по трём аккаунтам по кругу, с паузами против бана, пишет отчёт.

## Одна кнопка

```
bash ~/kord-bridge/рассылка/старт.sh
```

- `bash старт.sh тест` — прогон без отправки (сухой запуск, посмотреть что уйдёт)
- `bash старт.sh` — отправка в фоне, лог в `рассылка.log`, отчёт в `отчёт-рассылки.txt`

## Что нужно на сервере (один раз)

1. `pip3 install telethon` (задание деплоя ставит само)
2. Сессии трёх аккаунтов: `sessions/acc1.session`, `acc2.session`, `acc3.session`
3. `конфиг.json` рядом со скриптом (НЕ в репозитории, секреты в дом не идут):

```json
{"api_id": 0, "api_hash": "", "sessions": ["acc1", "acc2", "acc3"], "pause": [240, 600]}
```

## Правила рассылки

- Только целевые отклики на публичные запросы «нужен разработчик» — не спам по холодной базе.
- Пауза между сообщениями 4–10 минут, аккаунты по кругу: защита от бана.
- Один лид — одно сообщение. Повторы — только после диалога.
- Каждый запуск пишет отчёт: кому, чем, через какой аккаунт.
