- Сервер: kord-vps-01 (ssh root@45.152.198.192, вход по ключу, без пароля). ~3.8 ГБ RAM, 59 ГБ диск.

- Код вручную в Termux больше НЕ копируем — только через этот мост.

## Как работает мост (kord-bridge)
- Я (Perplexity) пишу файлы и код прямо в этот репозиторий через GitHub-коннектор.
- Сервер сам забирает обновления: bridge/update.sh (git fetch + reset --hard origin/main).
- bridge/update-loop.sh — цикл каждые 10 секунд под PM2: pm2 start bash --name kord-bridge-loop -- /root/kord-bridge/bridge/update-loop.sh
- Cron-строку с update.sh убрать после включения цикла.
- Секреты и токены в мост НЕ попадают никогда.
