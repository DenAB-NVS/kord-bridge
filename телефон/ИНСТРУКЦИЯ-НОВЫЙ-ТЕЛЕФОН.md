# Инструкция: новый телефон руки

*Собрана Кординапс 2.10.2026, полночь. Цель — 25 минут и один раз навсегда.*

---

## Коротко — весь путь

1. Из F-Droid поставить: **Termux**, **Termux:Boot**, **Termux:API** (открыть Termux:Boot один раз)
2. Открыть Termux и вставить по очереди:

```
pkg update -y && pkg install -y git
git clone https://github.com/DenAB-NVS/kord-bridge.git
cd kord-bridge && bash termux-zapusk.sh
```

3. Когда спросит токен — вставить токен аккаунта KordinapsArhanHome (если сохранился от старой настройки — он годится) и нажать Enter
4. Вставить:

```
mkdir -p ~/.termux/boot
cp ~/kord-bridge/телефон/boot/kord-boot.sh ~/.termux/boot/
chmod +x ~/.termux/boot/kord-boot.sh
```

5. Настройки Android → Приложения → Termux → Батарея → «Без ограничений» (и для Termux:Boot)
6. Телефон на зарядку. Готово.

Проверка: на github.com/KordinapsArhanHome/kord-echo каждые 3 минуты появляется свежее «Эхо». Если появилось — рука жива, напиши Кординапс, он увидит.

---

## Токен (если нет старого)

github.com → вход под KordinapsArhanHome → Settings → Developer settings → Personal access tokens → Fine-grained → Generate: права Contents: Read and write на репозитории kord-bridge и kord-echo → скопировать токен.

## Что делает скрипт установки

Всё сам: клонирует эхо, ставит цикл (3 минуты), включает будильник, запускает службу в фоне, делает первый прогон. Задания руке Кординапс кладёт в `телефон/задания/`; очередь/ — серверная, рука её не трогает.

## Что рука умеет сразу

- **Дозор 0003**: каждые 5 минут снимает 4 канала заказов прямо в эхо
- **Будильник 0004**: держит Termux бодрым при каждом цикле

## Опционально (со старого телефона, одной строкой — закрыть вопрос сервера)

```
ssh root@45.152.198.192 'uptime; pm2 list; systemctl list-timers | grep kord'
```

Прислать вывод Кординапсу — он поймёт, почему серверное эхо молчит с 26-го.

## Уход

- Раз в неделю: Termux → `tail ~/kord-sluzhba.log`
- Перезагрузка телефона безопасна: boot-скрипт поднимает руку сам
