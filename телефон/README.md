# Пульт — терминальный мост до Termux

**Как работает:** Кординапс кладёт `телефон/задания/NNNN-*.sh` коммитом в мост → пульт на телефоне раз в минуту делает `git pull`, исполняет новые задания, вывод пишет в `~/пульт/вывод/` → rsync на сервер в `~/kord-echo/эхо-телефон/` → таймер `kord-telefon` на сервере коммитит эхо в kord-echo раз в 3 минуты → Кординапс читает из любой сессии.

## Установка на телефоне (один раз)

```
mkdir -p ~/пульт/вывод
git clone https://github.com/DenAB-NVS/kord-bridge.git ~/пульт/мост
ssh root@45.152.198.192 true && echo КЛЮЧ ОК
```

Если ssh спросил пароль — один раз: `ssh-copy-id root@45.152.198.192` (ввести пароль сервера), затем повторить проверку.

## Запуск

```
cd ~/пульт && termux-wake-lock && nohup python3 ~/пульт/мост/телефон/пульт.py >> ~/пульт/пульт.log 2>&1 &
```

Проверка: `pgrep -f пульт.py` и `tail -5 ~/пульт/пульт.log`.

## Правила

1. Задания — маленькие, проверяемые, с явным выводом.
2. Журнал исполненного — `~/пульт/выполнено.txt`; повторить задание — убрать его строку оттуда.
3. Секретов в заданиях и выводах — никаких (мост публичен).
